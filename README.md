# 网页分享优化版

本发布目录包含网页加载和手机兼容性优化。

网页预览：http://127.0.0.1:8766/?preview=fast-20261005

发布包是本次优化版；线上是否已更新，以本次发布结果为准。预览地址仅在这台电脑的预览服务运行时可用。

## 本次完成

- 保留页面结构、紫色短裤、原地扇翅飞鸟、灌木人物和六只祝尼魔彩蛋。
- 将原先 669KB 的完整像素字体精简至 18KB；页面文字保持像素字体，陌生宾客姓名使用系统字体补全。
- 把图标从大型截图中独立出来，裁掉无需下载的素材图部分，压缩显示图片。源素材仍保留。
- 图片按浏览位置加载；音乐、灌木视频在用户触发后加载。完整音乐从 8.33MB 优化到 2.50MB。
- 已加入一张新人照片（优化为 154KB），六份祝福集齐后显示。已移除寄语和寄语占位。
- 图片请求失败后每隔 30 秒重试，最多三次；灌木视频加载失败仍能显示人物和收集祝尼魔。
- 停止屏幕外动画；补充旧版手机浏览器的动画、选择状态及弹窗兼容处理。
- 姓名、电话和留言仍只保存在当前访客浏览器，没有上传接口。

## 测试结果与边界

同一台电脑，同一 Chromium 引擎，390×844，禁用缓存，网络模拟 200KB/s 下载与 150ms 延迟：

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 首屏最大内容显示 LCP（15 秒观察窗口） | 11.72 秒 | 1.09 秒 |
| 像素字体文件 | 668,552 字节 | 17,832 字节 |
| 首页山谷图片 | 366,187 字节 | 51,536 字节 |
| 首屏音乐 / 视频请求 | 有 | 无 |

这是受控的本机限速测试，不能直接代表微信或所有运营商的实际速度。当前网络实测旧站 HTML 首字节约 0.75 秒；旧字体 669KB 下载约 19.4 秒，说明页面体积和跨境链路都影响体验。

375px、390px、430px 已通过文字/表单/横向溢出检查；彩蛋、照片解锁、音乐、登记保存修改清除、存储失败提示已检查。另验证了视频请求失败、无原生 dialog 支持、离线登记和图片 30 秒重试。尚未在实体 iPhone/安卓微信中验证。

详细结果位于 `performance-checks/` 和 `checks/video-version/results.json`。

## 后续如何修改

编辑 `public/config.js` 可调整日期、地点、交通和照片列表；照片放入 `public/assets/fast/`，建议每张 150–300KB。照片宽高写实际尺寸。日期、姓名若需同时调整装饰文字，可继续交给我统一修改。

已经生成独立发布目录 `网页分享优化版/`。上传时使用该目录内文件，不要把旧视频帧、原始素材或备份上传。保留原文件名时，浏览器可能短暂使用缓存；更新照片建议采用新文件名并同步配置。

## 若 GitHub 链路仍不稳定

先更新当前 GitHub Pages 版本，在微信用移动网络实际打开。若仍存在主文件连接超时或资源持续缓慢，再迁移到能提供更合适访问区域的静态托管。

腾讯 EdgeOne Pages 可以配置加速区域；使用中国大陆可用区的自定义域名需完成备案。尚未购买域名、开通付费服务或迁移网站。跨境节点不保证所有地区和网络都快，需要实际测试。
